⚡ 4-Tier Hybrid Conversion Pipeline

Every file is inspected via binary magic bytes and routed to the lowest-overhead execution tier capable of handling the format and file size.

Tier 1: LOCAL_NATIVE (Browser Hardware APIs) 0 KB Extra • Instant
OffscreenCanvas (PNG, JPEG, WEBP, AVIF, BMP, ICO, SVG), WebAudio API + PCM WAV encoder, WebCodecs, native CompressionStream (GZIP/Deflate).
Tier 2: LOCAL_PURE_JS (Web Worker Compute) < 50 KB • Zero Upload
CSV ↔ JSON ↔ YAML ↔ XML ↔ TOML ↔ INI ↔ Markdown ↔ HTML ↔ SQL INSERT, streaming ZIP/TAR archive engine, and client-side PDF generation/splitting.
Tier 3: LOCAL_WASM (Lazy On-Demand WebAssembly) Cached in IndexedDB
Fetched only when needed inside isolated Web Workers with OOM watchdog: FFmpeg.wasm (MP4/WEBM/MP3/FLAC/GIF), ImageMagick.wasm (TIFF/PSD/RAW/HEIC), DuckDB.wasm (Parquet).
Tier 4: SERVER_FALLBACK (Managed Backend Queue) SSE Live Progress + Auto-Purge
Handles non-browser formats (LibreOffice DOCX/PPTX/XLSX → PDF, Pandoc EPUB/LaTeX, 7z/RAR/CAD) or files exceeding safe client RAM thresholds.
